# Security Policy

## Supported Versions
- Only the latest version of Authence is actively maintained and patched.

## Reporting a Vulnerability
- Jika Anda menemukan kerentanan keamanan, harap segera laporkan melalui email ke maintainer atau gunakan fitur Issues dengan label `security` (jika tidak sensitif).
- Jangan publikasikan detail kerentanan sebelum ada patch/respons dari maintainer.
- Kami akan merespons laporan keamanan secepat mungkin.

## Best Practice
- Selalu gunakan versi terbaru.
- Jangan pernah expose secret/JWT/private key di public repo.
- Audit dependensi secara berkala.

Terima kasih atas kontribusi dan perhatian Anda terhadap keamanan proyek ini!
